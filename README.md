# Yayla — Web Test Build

Oyna: https://kursatsndgn.github.io/yaylatest/
Oyunun tarayıcıda denenebilen test sürümü (Godot 4.7.1, thread'siz web export). Kaynak kod: `kursatsndgn/yayla` (private).

**PC:** WASD yürü · Shift koş · Space zıpla · Fare kamera (önce ekrana tıkla) · F / sağ tık fotoğraf · Sol tık çek · E etkileşim · Tab herbaryum · Esc mola

**Telefon / tablet:** sol başparmak joystick (kenara itince koşar) · sağda sürükle kamera · Zıpla, Fotoğraf/Çek, Etkileşim, Defter, Mola butonları · konuşmada ekrana dokun.

"WebGL 2" uyarısı görürsen: tarayıcı ayarlarından grafik hızlandırmayı aç ve tarayıcıyı yeniden başlat.
